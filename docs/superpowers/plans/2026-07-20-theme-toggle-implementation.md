# Theme Toggle (Light / Dark) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a working light/dark theme toggle to the portfolio using the Lightswind `ToggleTheme` component with the `circle-spread` animation.

**Architecture:** Add a light palette as a `:root.light` block in `src/index.css` that overrides the existing dark CSS variables. Install Lightswind's `ToggleTheme` component, mount it in the navbar between Search and Get in touch (desktop) and inside the mobile drawer footer (mobile). Lightswind manages the `dark` class on `<html>`; we suppress dark-only decoration (vignette, grid-bg, hero glow) in light mode via existing class hooks.

**Tech Stack:** React 19, Vite 6, Tailwind v4, `lightswind` (newly added), `framer-motion`, existing CSS variable system.

**Spec:** `docs/superpowers/specs/2026-07-20-theme-toggle-design.md`

## Global Constraints

- Library added via `npx lightswind@latest add toggle-theme` — do not hand-write the component.
- Import path: `import { ToggleTheme } from "@/components/lightswind/toggle-theme";` (translate to actual relative path Lightswind generates; the spec assumes `@/components/...` aliased resolution — verify by reading `vite.config.js` and the CLI's generated path).
- Toggle animation: `animationType="circle-spread"`, `duration={600}`.
- Light palette tokens (warm off-white) per spec §2 — exact hex/rgba values listed in Task 1.
- Do not modify the existing dark palette values.
- `html { color-scheme }` must be set to `light dark` (not just `dark`).
- Index.html currently has `<html data-theme="dark" class="dark">` — keep both attributes; Lightswind reads the class.

## Task 1: Add the light palette to `src/index.css`

**Files:**
- Modify: `src/index.css:27-49`

**Goal:** Add a `:root.light` CSS variable block with the warm off-white palette and update the `color-scheme` so native chrome (scrollbars, form controls) follow the theme.

- [ ] **Step 1: Add the light theme block after the existing `:root { ... }` block**

In `src/index.css`, after the closing brace of the existing `:root` rule (line 39, before `@layer base`), insert:

```css
:root.light {
  --bg-base: #f5f4ef;
  --bg-elev1: #ecebe4;
  --bg-elev2: #e3e1d8;
  --fg: #1a1a1c;
  --fg-muted: rgba(26, 26, 28, 0.66);
  --fg-dim: rgba(26, 26, 28, 0.42);
  --border: rgba(26, 26, 28, 0.10);
  --border-hi: rgba(26, 26, 28, 0.18);
  --accent: #1a1a1c;
  --accent-glow: rgba(26, 26, 28, 0.06);
}

/* Suppress dark-only decoration in light mode */
:root.light .vignette::before {
  display: none;
}

:root.light .grid-bg {
  display: none;
}
```

- [ ] **Step 2: Update `html` color-scheme**

In the same file, inside the `@layer base` block, change:

```css
  html {
    scroll-behavior: smooth;
    color-scheme: dark;
  }
```

to:

```css
  html {
    scroll-behavior: smooth;
    color-scheme: light dark;
  }
```

- [ ] **Step 3: Verify visually**

Run: `npm run build`
Expected: build succeeds, no errors. Open `npm run dev` and, using the browser console, run `document.documentElement.classList.add('light')` — the entire page should switch to the warm off-white palette. Run `.remove('light')` to revert.

- [ ] **Step 4: Commit**

```bash
git add src/index.css
git commit -m "feat(theme): add light palette CSS variables"
```

Temporarily import it in `Layout.jsx` (one-line change), run `npm run dev`, and click the toggle. Verify:

## Task 3: Wire the toggle into the navbar (desktop + mobile)

**Files:**
- Modify: `src/Components/Navbar/Navbar.jsx:1-12, 67-80, 165-178`

**Goal:** Add the toggle to the desktop right cluster and the mobile drawer footer without disrupting existing layout.

- [ ] **Step 1: Add the import**

At the top of `Navbar.jsx`, add (path resolved from Task 2):

```jsx
import { ToggleTheme } from "../../components/lightswind/toggle-theme";
```

(If the relative path differs based on where the CLI placed the file, adjust accordingly.)

- [ ] **Step 2: Insert the toggle in the desktop cluster**

Locate the desktop right-cluster block (around lines 68–80). Between the Search button and the `PrimaryCTA "Get in touch"`, insert:

```jsx
<div className="inline-flex h-[34px] w-[34px] items-center justify-center rounded-sm border border-border bg-[var(--bg-elev1)] text-[var(--fg-muted)] transition-colors duration-300 hover:border-[var(--border-hi)] hover:text-fg">
  <ToggleTheme animationType="circle-spread" duration={600} />
</div>
```

Final cluster order becomes:

```
[Search ⌘K]  [☾/☼ chip]  [Get in touch →]
```

- [ ] **Step 3: Add the toggle to the mobile drawer footer**

Locate the mobile drawer footer (around lines 165–178) — the row containing `v2026` and `Get in touch`. Add the toggle between them:

```jsx
<div className="mt-8 flex items-center justify-between">
  <span className="mono-label" style={{ color: "var(--fg-dim)" }}>
    v2026
  </span>
  <div className="inline-flex h-[34px] w-[34px] items-center justify-center rounded-sm border border-border text-[var(--fg-muted)] transition-colors hover:border-[var(--border-hi)] hover:text-fg">
    <ToggleTheme animationType="circle-spread" duration={600} />
  </div>
  <PrimaryCTA
    variant="outline"
    size="sm"
    to="/contacts"
    onClick={() => setOpen(false)}
  >
    Get in touch
  </PrimaryCTA>
</div>
```

If the three-element row feels too wide on small screens, switch to `flex-wrap` with `gap-4` so it wraps cleanly.

- [ ] **Step 4: Verify build**

Run: `npm run build`
Expected: clean build.

Run: `npm run dev` and confirm:
- Desktop: chip appears between Search and Get in touch, matches their height.
- Mobile: opening the hamburger menu shows the toggle in the footer row.
- Clicking either toggle flips the entire site palette with the circle-spread animation.
- Reloading the page preserves the chosen theme.

- [ ] **Step 5: Commit**

```bash
git add src/Components/Navbar/Navbar.jsx
git commit -m "feat(theme): mount ToggleTheme in navbar (desktop + mobile)"
```
